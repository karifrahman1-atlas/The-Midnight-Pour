# The Midnight Pour — D + B brand voice

A dark, considered coffee-house concept for a Dhanmondi, Dhaka portfolio website. The voice is sophisticated with subtle humour: confident, warm, never trying too hard.

## Files
- `index.html` — page structure, section copy, metadata and FAQs
- `styles.css` — visual styling and responsive layout
- `script.js` — menu tabs, mood selector, mobile navigation and current year

## Before presenting as a live business
This is a portfolio concept. Confirm the real business name, address, menu, prices, opening hours, facilities and photos before publishing it as a real café website. The listed menu and prices are illustrative.
