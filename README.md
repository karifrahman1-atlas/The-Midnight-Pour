# The Midnight Pour — café website

Static website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page structure, SEO metadata, menu, local content and FAQ
- `styles.css` — responsive styling and remote image/font assets
- `script.js` — menu category tabs, coffee mood selector, mobile navigation and FAQ details

## Before using for a real business
Verify the brand, menu, prices, address, Google Maps pin, contact channels, opening hours, available facilities, seating, reservation policy and all operational claims. The current Maps link opens the Dhanmondi area, not a verified business pin. Social profiles, ordering, reservations, analytics and conversion tracking are not connected. Add these only when the business has confirmed details and the required systems.

## SEO notes
The page includes a title, meta description, canonical URL and Open Graph/Twitter metadata. Review the canonical URL before deploying to another domain. No address-based LocalBusiness schema is included because a verified street address and business details have not been supplied. Once the real details are available, add accurate structured data and confirm indexing in Google Search Console.

## Deploy
Replace the files in the connected GitHub repository and commit to trigger a Netlify deploy, or deploy this folder directly.
